# 官方一手资料入口

下列是**检索入口**，不是对任意视频结论的自动背书。具体结论需要实际打开相应章节和源码版本后才能引用。

- Bootlin 培训教材：https://bootlin.com/docs/ （以及 https://bootlin.com/training/）
- Bootlin 内核源码 Elixir：https://elixir.bootlin.com/linux/latest/source/
- Linux Kernel Documentation：https://docs.kernel.org/
- Linux upstream Git：https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/
- Linux stable Git：https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git/
- Linaro 官网：https://www.linaro.org/
- Linux Foundation 培训：https://training.linuxfoundation.org/
- Kernel Newbies（社区补充，非标准源）：https://kernelnewbies.org/
- Yocto Project Documentation：https://docs.yoctoproject.org/
- Buildroot Manual：https://buildroot.org/downloads/manual/manual.html
- Devicetree Specification：https://www.devicetree.org/specifications/
- Linux Plumbers Conference：https://linuxplumbersconf.org/

引用规范：视频时间码 + 资料标题/版本 + 可验证链接 + 是否为讲者直接陈述。
